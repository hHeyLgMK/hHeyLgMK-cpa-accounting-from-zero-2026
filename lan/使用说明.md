# CPA 刷题库：电脑与手机局域网同步版

本包包含当前仓库六科 4,412 道题。数据保存在电脑磁盘和设备浏览器，不需要云账号、云数据库或互联网连接。手机用浏览器访问电脑提供的刷题网页。

## 第一次启动

1. 电脑需要 Python 3.9 或更新版本。安装时勾选 **Add Python to PATH**。这份下载包没有内置 Python。
2. 解压整个压缩包，不要只取其中的单个文件。Windows 双击 `lan/start-windows.bat`。macOS/Linux 在包的根目录运行 `python3 lan/server.py`。
3. 电脑浏览器会自动打开。启动窗口会显示 **配对码**、**电脑地址**及一到多个 **手机地址**。
4. 电脑连接手机热点；手机浏览器打开启动窗口显示的 `http://电脑IP:8765/` 地址。也可两端连接同一路由器。
5. 两端展开网页顶部的 **局域网同步**，输入启动窗口显示的 8 位配对码，点击 **配对**。第一台设备点击 **用本机记录接管** 初始化共享记录。

同步期间保持电脑开机、同步窗口打开和局域网连接。手机作为热点主机通常可以访问热点内的电脑，但具体手机的热点隔离设置可能阻止连接，需要实际验证。

## 换设备接着刷题

- 当前设备答题后约每 2 秒上传变更，看到 **已同步** 后再切换。
- 另一台设备点击 **在本机继续**，会获取当前科目、章节、知识节、题号、选项顺序、所选答案、简答草稿、提交状态、练习历史、错题、标记和模拟剩余时间。
- 一次仅一台设备答题。另一台同步查看，模拟计时暂停，不能点击答题控件。切换时旧设备会在下次轮询后进入查看模式。
- 切换时若旧设备还有未上传的改动，服务端会拒绝旧设备继续写入；旧设备保留本机记录并提示冲突，不自动叠加两端统计。
- 若网络中断，当前答题设备仍保留本机记录；连接恢复后会重试。如果另一个设备已接管，会提示冲突。
- 点击 **暂停同步 / 离线** 可以离线刷题。下次连接后，选择采用共享记录，或明确用本机记录接管。
- 即使刷新或关闭浏览器，题目和草稿仍按原有逻辑保存。重新配对后点击 **在本机继续** 读取电脑保存的进度。

## 备份与冲突

- **导出本机及备份** 下载 JSON，包括当前记录和最近 5 次主动替换/冲突前的本机备份。
- 导入 JSON 时，先暂停同步，再选择备份文件。导入恢复文件中的 `current` 记录。若需恢复其中某个历史备份，先把其 `snapshot` 放到 `current` 字段，再导入。
- 电脑的完整同步数据保存在 `lan-data/sync.json`，上一份记录在 `sync.previous.json`。每次用本机记录替换已有共享记录，还会在 `lan-data/backups/` 留存接管前的完整记录，不会被后续轮询覆盖。
- 题库版本变化时服务会拒绝直接沿用不匹配的数据文件，防止恢复到不存在的题目。先备份旧数据，再明确迁移。

## 已有 Windows EXE / Android APK

**本包是局域网网页版，不是 APK 更新包。旧 APK 和旧 EXE 的本地记录不会自动读取或迁移。**浏览器同一来源的数据才能直接沿用，换 IP、端口或浏览器也会使用另一份本机记录；配对后可从电脑的共享记录恢复。

仓库没有 Android 原生壳源码。要让 APK 内直接配对，还需要更新 Android 壳、局域网访问设置与内置网页。不要卸载旧 APK 来迁移数据；卸载可能清除旧记录。

仓库新版网页及重新构建的 Windows 离线网页有进度导出/导入入口，可以导出新版工具的记录后导入此版本。已有旧 APK 尚未有这个入口时，无法仅凭本包取出其沙箱中的旧记录。

## 手机打不开

1. 确认手机地址里的 IP 是电脑连接热点的 IPv4 地址，可在电脑 `ipconfig` 的 Wi-Fi 项中查看；不要在手机输入 `127.0.0.1`。
2. 同步窗口必须仍在运行。手机需要访问 `http://` 地址，注意端口 `8765`。
3. Windows 防火墙如询问，允许该服务在当前可信网络上通信；不要关闭整个防火墙。若没有询问，可为 Python 程序的 TCP 8765 入站连接添加仅限当前可信网络的规则。
4. 若有多个“手机地址”，选热点 Wi-Fi 对应地址。VPN、虚拟网卡的 IP 可能不可达。
5. 如果手机热点阻止访问电脑，可改为双方连接同一个家用 Wi-Fi，或让电脑开启热点、手机连接电脑热点。

## 验证范围

自动测试覆盖原有六科题库与退出续答、新设备接管、整份进度恢复、不重复计分、被动端暂停计时、断网重试、冲突保留、服务重启、并发版本检查、配对码与请求来源检查。没有在用户的真实手机热点或 Windows 电脑上实测；本运行环境缺少可启动的 Chromium，未完成真实浏览器界面实测。
